# puxa-capivara

Search for a politician by name and download a one-page PDF summarizing their public life: bills introduced
and passed, votes on the most important bills, lawsuits and investigations, declared assets, and what they
have said about the hot topics of the moment.

**Initial scope:** president, governors, federal deputies, and senators.
**Principle:** public data only, from official and free sources, with a link to the source of every piece of information.
**Hosting:** Google Cloud (Cloud Run, Cloud Storage, Firebase Hosting), São Paulo region.

## Status

Phase 1 in progress: master registry, key votes, legislative output, the PDF profile (draft v1), and site v1
(search, profile, and PDF) for the 862 people in the registry. Sources validated live ([report](docs/source-validation.md)).

## Pipeline

Python 3.13 + [uv](https://docs.astral.sh/uv/).

```bash
cd pipeline
uv sync
uv run pytest -q          # tests (no network)
uv run puxa registry      # builds the master registry in data/processed/registry/
uv run puxa votes         # votes on the key roll calls (curation/key_votes.yaml)
uv run puxa bills         # bills introduced and those that became law, since 2019
uv run puxa photos        # official photos (Chamber, Senate, or TSE)
uv run puxa profile erika-hilton lula   # one-page profile in data/site/pdf/ (or --all)
uv run puxa site          # site data in data/site/web/ (index, JSON profiles, photos, PDFs)
```

## Site

Next.js 16 (Node 22). Search by name, the person's profile, and a button to export the PDF. Reads data from
`data/site/web/` (generated by `uv run puxa site`) or, in production, from Cloud Storage.

The site's interface and the PDF stay in Portuguese because the audience is Brazilian voters; the code and the
documentation are in English.

```bash
cd site
npm ci
npm run dev               # http://localhost:3000
npm test                  # tests for search and Cloud Storage reading
```

Downloaded and generated data lives in `data/` (outside Git). Manual corrections live in `curation/`.
